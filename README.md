# ColabMonkeytype
### Monkeytype but in Colab. 

* This repository is based off Monkeytype, an original project by miodec, and maintained by the contributors in https://github.com/monkeytypegame/monkeytype 

<br> 

## How to Run
1. Make a Google Colab account at https://colab.research.google.com 
2. Download the ipynb file from this repo and upload the notebook to Google Colab
3. Run both cells in order
4. Optional: open the cell output in full screen

<img width="286" height="138" alt="fullscreen " src="https://github.com/user-attachments/assets/8df0a388-8381-475a-b225-a9ed6c3dbf5c" />

<br> 

<br> 

Afterwards, it will be set up over the cloud and will not require internet access (as long as you keep the colab tab open) or rebuilding. 

A known limitation is that you are unable to login to your Monkeytype account in the cell's output as the ipynb uses a dummy Firebase config.
