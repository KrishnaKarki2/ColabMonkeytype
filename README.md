# ColabMonkeytype
### Monkeytype but in Colab. 

* This repository is based off Monkeytype, an original project by miodec, and maintained by the contributors in https://github.com/monkeytypegame/monkeytype 

<br> 

Download and upload the ipynb file to Google Colab and run both cells in order. Afterwards, it will be set up over the cloud and does not require internet access (as long as you keep the colab tab open) or rebuilding.
